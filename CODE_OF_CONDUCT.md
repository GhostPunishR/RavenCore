# Code de conduite

RavenEmu Cores accueille les contributions techniques de tous les niveaux, dans un cadre respectueux.

## Comportement attendu

- Échanger avec courtoisie, y compris en cas de désaccord technique.
- Critiquer le code et les arguments, pas les personnes.
- Accueillir les questions, les corrections et les contributions de bonne foi.
- Respecter la vie privée, les licences et le travail des autres.

## Comportement inacceptable

Le harcèlement, les menaces, les insultes, les attaques personnelles, les propos discriminatoires, les divulgations de données privées et les provocations répétées ne sont pas acceptés.

## Application

Ces règles s'appliquent aux issues, pull requests, revues et autres espaces de collaboration liés au projet. Le mainteneur peut modérer, masquer ou supprimer du contenu et limiter la participation en cas de violation.

Pour un problème de comportement, utilisez un moyen de contact privé disponible sur le [profil GitHub du mainteneur](https://github.com/GhostPunishR) ou les outils de signalement de GitHub. N'exposez pas d'informations personnelles dans une issue publique.

Ce code de conduite est propre à RavenEmu Cores.
