# Sécurité

Les moteurs traitent des fichiers non fiables : ROMs, sauvegardes batterie, états instantanés et données transmises par un frontend.

## Signaler une vulnérabilité

**Ne publiez pas d'exploit, de données sensibles ou d'instructions d'attaque dans une issue publique.**

Si GitHub propose le bouton **Report a vulnerability** dans l'onglet **Security** du dépôt, utilisez ce canal privé. Sinon, recherchez un moyen de contact privé sur le [profil du mainteneur](https://github.com/GhostPunishR) ou utilisez les mécanismes de signalement appropriés de GitHub.

Fournissez, dans la mesure du possible, le composant concerné, la version ou le commit, l'impact, les étapes de reproduction et un cas de test minimal ne contenant aucune ROM commerciale ni donnée privée.

Les problèmes de compatibilité ordinaires peuvent être signalés à l'aide des [modèles d'issues](.github/ISSUE_TEMPLATE/). Aucune politique de délai de réponse ou de support de versions particulières n'est garantie à ce stade.
